Code du travail

Le Code du travail rassemble l’ensemble des règles juridiques qui régissent les relations entre employeurs et salariés en France. Il définit les droits et obligations de chaque partie, notamment en matière de contrat de travail, de durée du travail, de santé et de sécurité, de congés, de rémunération, de licenciement et de représentation du personnel.

Cette page offre une introduction concise ; pour un accès complet aux articles, consultez le site officiel du gouvernement ou la version en ligne du Code du travail.
